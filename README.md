# 闲鱼新货雷达

这是一个通用的闲鱼关键词上新监控器。你可以在面板里填写任意搜索关键词和价格门槛；程序每轮在闲鱼搜索页选择“新发布 → 最新”，把符合条件的商品加入面板并显示 Windows 文字弹窗。当前默认示例是 `mardi短袖`、低于 `60` 元，扫描完成后依次等待 `1、2、3、4、5` 分钟，再从 `1` 分钟循环。

只有同时满足以下条件的商品才会推送：

- 商品 ID 是建立基线后第一次出现；
- 标题与搜索关键词相关；
- 当前价格严格低于你设置的门槛，等于门槛不会推送。

每个关键词的首次扫描只记录当前商品作为基线，不推送历史低价商品。不同关键词的已见商品和推送记录相互隔离，状态保存在 `monitor_state.json`，Microsoft Edge 登录态保存在 `.edge-browser-data`。登录模式长期复用该独立资料目录，不定时清除 Cookie 或缓存，也不会读取日常 Edge 的个人资料。

## 启动

直接双击 `start_dashboard.cmd`，或者在 PowerShell 中执行：

```powershell
cd D:\咸鱼监控
.\.venv\Scripts\python.exe .\dashboard.py
```

控制面板会自动打开：`http://127.0.0.1:8765`

面板启动后默认自动开始监控。监控窗口使用本机安装的 Microsoft Edge，可以选择“登录模式”或“游客模式”，并在界面中暂停、立即扫描、修改关键词、价格上限和刷新方式，以及开关 Windows 文字弹窗。登录模式使用独立的 `.edge-browser-data` 保存登录态；游客模式使用临时浏览器会话，只读取平台正常提供的公开搜索页面，不保存账号登录态。脚本每个会话只维护一个商品搜索页面，不会自动打开商品详情页。刷新方式默认使用 `1-5 分钟循环`；切换到“固定秒数”后，可输入 `30` 到 `3600` 之间的任意整数秒。刷新方式、固定间隔和系统文字弹窗均可在监控运行中实时修改，修改关键词、价格或访问方式前需先暂停。重新启动后新关键词会单独建立基线。

## 企业微信与钉钉通知

在面板左侧的“消息通知”区域点击“设置”，即可分别配置企业微信和钉钉。通知渠道开启后，只有建立基线后新出现、关键词相关且严格低于价格门槛的商品才会发送；首次扫描不会发送历史商品。Webhook 发送失败不会停止闲鱼监控，失败状态会显示在面板和运行记录中。企业微信开启并配置后，检测到验证码、访问受限或登录异常时，还会优先推送一条安全暂停告警，包含关键词、发生时间和脱敏后的异常信息。

商品存在可信图片地址时，企业微信发送带商品封面的图文消息，钉钉在 Markdown 消息中显示商品图；图片缺失、仍是占位图或地址不可信时自动退回文本消息。企业微信图文消息的主卡片会从抓取使用的网页地址转换为闲鱼官方移动商品入口，手机点击后优先进入闲鱼 App 或对应的移动详情，并用第二个卡片保留“网页备用”入口。微信、企业微信以及手机系统可能要求再次确认打开 App，程序无法绕过客户端的外部应用安全确认。

企业微信配置：

1. 在企业微信群中添加机器人或消息推送，复制以 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=` 开头的 Webhook 地址。
2. 把地址粘贴到企业微信输入框，点击“测试企业微信”。收到测试消息后打开右侧开关，再点击“保存设置”。
3. `work.weixin.qq.com/.../openBotProfile/...` 是机器人资料页，不是可发送消息的 Webhook，面板会拒绝保存。

钉钉配置：

1. 在钉钉群中添加自定义机器人，复制以 `https://oapi.dingtalk.com/robot/send?access_token=` 开头的 Webhook 地址。
2. 如果机器人启用了“加签”，同时填写机器人提供的加签密钥；未启用则留空。如果使用“自定义关键词”安全设置，请把关键词设为 `闲鱼`，测试消息和商品消息都会包含它。
3. 点击“测试钉钉”，收到测试消息后打开右侧开关，再点击“保存设置”。

Webhook 地址和钉钉加签密钥属于凭据，只在本机输入，不要发到聊天、截图或提交到 Git。程序把它们保存在项目目录下的 `notification_config.json`；该文件已加入 `.gitignore`，状态接口和界面不会回传凭据，但文件内容本身是本机明文。点击某个渠道的“移除”会从本机配置中删除该渠道的地址和密钥。

## 首次安装

仅在 `.venv` 尚未安装依赖时执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --timeout 60
.\.venv\Scripts\python.exe -m playwright install chromium
```

## 运行说明

- 监控浏览器必须保持打开。首次登录或登录态失效时，请在程序打开的 Edge 窗口中手动登录闲鱼；脚本不会自动填写账号或验证码。
- 登录模式首次启动时如果尚未登录，程序会等待你完成登录；游客模式不会主动登录，如果公开页面要求登录则进入人工处理状态。
- 运行中一旦检测到验证码、访问受限或登录状态失效，会立即暂停扫描且不会自动重试，同时保留当前浏览器和提示页面。人工处理完成后，在面板点击“继续监控”会复用当前页面；点击“关闭浏览器”才会结束会话。
- 上述安全暂停事件会通过已启用的企业微信机器人推送；如果企业微信未配置或发送失败，不会影响暂停和人工验证流程，失败原因会记录在面板和 `dashboard_debug.log` 中。
- 普通网络或页面错误会保持当前会话，并按连续失败次数依次冷却 `15、30、60` 分钟；第三次以后继续使用 `60` 分钟。扫描恢复成功后错误计数自动归零。
- 面板会显示当前会话时长、该页面产生的请求数量和安全暂停次数，只记录数量与时长，不保存请求内容。
- 脚本不会读取或保存手机号、密码、验证码，也不会绕过安全验证。
- 面板仅监听本机 `127.0.0.1`，不会向局域网公开。
- 完整运行日志保存在项目目录的 `dashboard_debug.log`，最多保留当前文件和 3 个轮转文件。界面操作失败时会显示接口状态并写入脱敏摘要，Webhook 地址和密钥不会写入日志。
- 修改代码后必须完全关闭原启动窗口，再重新双击 `start_dashboard.cmd`；页面提示“控制服务仍是旧版本”时，说明后台进程尚未重启。
- 按启动终端中的 `Ctrl+C` 可完全关闭面板和监控。
- 闲鱼网页结构发生变化时，本轮会显示错误并按异常冷却时间重试。
- 请保持合理扫描间隔并遵守闲鱼的平台规则。
